Privacy

Privacy policy

Agent-Town for Claude Code is made of two parts: the app (for macOS and Windows) and town-link, a plugin for Claude Code. Neither part has an account, collects analytics, or sends anything to the people who make Agent-Town. This page lists what each part reads and sends.

In short

  • What Claude Code is doing is sent only to the Agent-Town app on your own computer, never over the internet.
  • To name each task, the plugin asks Claude's Haiku model through Claude Code, on your own Claude plan. Nothing goes to any other service.
  • The app checks GitHub once a day for a newer version. You can turn this off in Settings → Updates.
  • Nothing else leaves your computer.

The plugin (town-link)

town-link watches what Claude Code does: a session opening, a prompt you type, a tool being used, a helper (subagent) or background task starting and finishing, a request for your approval, how full the session's memory is. It turns these into short messages and sends them to the Agent-Town app over a connection that stays inside your computer (to the address 127.0.0.1). The app accepts only messages that carry a random key it created, so other programs can't feed it events.

Those messages contain the project's name (not its full folder path), the start of each prompt as you typed it (it appears on the ticket in the office), the names of tools in use, short descriptions of helpers and background tasks, the model in use, and the plugin's version.

For each new task, town-link asks Claude's Haiku model, through Claude Code and on your own Claude plan or API key, for a short title and the kind of task; for each helper or background task, it asks for a fitting job title. These requests include the start of the prompt or the helper's description. They are handled by Anthropic like any other Claude Code request on your account. If you'd rather not, turn town-link off with /town off in Claude Code.

town-link never changes what Claude Code does: it doesn't allow, refuse or edit anything. When the app isn't running, it drops the events instead of storing them.

The app

The app shows the events it receives and keeps nothing after it quits, apart from your settings (such as the language, sounds and window position), which stay on your computer.

Once shortly after it starts, and then once a day, the app asks GitHub for the list of Agent-Town releases and for the plugin's latest version number, to tell you when an update is available. The request contains nothing about you, your work or your computer beyond what any web request carries, such as your IP address, which GitHub handles under its own privacy statement. To turn the check off, open Settings → Updates and switch off "Check for updates automatically".

The installers

The Mac app (Homebrew or the .dmg) and the Windows installer only install the app. They don't send any information anywhere.

Other components

The app uses the operating system's own libraries, the Godot engine on Windows, and Kenney's 3D models. None of them send information on Agent-Town's behalf.

Questions

The source code is public, so everything on this page can be checked. Questions or concerns: open an issue on GitHub.
