Executive office

Watch Claude Code work, as a little office.

You give Claude Code a task, and then you wait. Agent-Town shows you what happens in between: who is working, who was called in, and when it needs you.

Download for Mac or Windows See it on GitHub

Free and open source. Works with Claude Code on your own computer.

Who's who

Each person in the office stands for something Claude Code is doing.

  • CEO

    That's you. Every prompt you type becomes a ticket, phoned through to the right desk. When Claude Code needs your OK, your phone rings.

  • Chief of Staff

    One Claude Code session. Takes your ticket, wears a hat for the kind of task, and phones you the report when it's done.

  • Staff

    The helpers Claude Code calls in, the subagents. They wait on the bench, walk to a desk, work, and report back.

  • Operators

    Long-running jobs in the background, like builds and tests, worked on at the racks of the server room.

  • Dispatcher

    Keeps the board of scheduled and repeating tasks, and radios each one to its Chief of Staff when it's due.

  • Inspector

    Stands at reception. When a check sends the work back, the Inspector stamps it "Returned" and the work goes on.

What you'll notice

See what's happening without reading the terminal.

A sound when it's done

Leave the office in a corner of your screen, or hide it. You still hear when work is dispatched, when it's finished, and when Claude Code is waiting for you.

One block per project

Each project you have open gets its own office block, with its name on the sign and a short title for the task under way.

A bar for the context

Under each block, a bar shows how full the session's context is: how much room is left before Claude Code compacts it.

On a laptop screen

Compact view draws the office at half size, idle projects can step out of sight, and a small window follows wherever people are walking.

English and 繁體中文

The app speaks English and Traditional Chinese, and follows your system's language.

It only watches

Agent-Town never touches your work. Events stay on your own computer, and nothing is sent to us. How it handles your data.

Why it exists

It started as a sound.

Some tasks in Claude Code take a long time. You type a prompt, it starts reading files, running commands and calling helpers, and you wait. I wanted to know two things: what is it doing right now, and is it done yet?

The first idea was small: play a sound when a long task finishes. But Claude Code already says a lot about what it's doing, which tool it's using, which helper it started, when it's waiting for approval. If every one of those moments can be heard, it can be seen. So the sound grew into an office.

Samson Chen, who made Agent-Town

Download

Two parts: the app, and a plugin for Claude Code.

The app draws the office. The plugin, town-link, tells it what Claude Code is doing. You need both.

Mac

macOS 15 or later. Signed and notarized by Apple.

With Homebrew:

brew tap samsonchen/agent-town-claude-code https://github.com/samsonchen/agent-town-claude-code
brew install --cask samsonchen/agent-town-claude-code/agent-town

Or download the latest .dmg and drag Agent-Town into Applications. It lives in the menu bar.

Windows

Windows 11. Installs for your user only, with no administrator prompt.

Download agent-town-setup from the newest agent-town for Windows release on the Releases page and run it. It lives in the tray.

The installer isn't code-signed yet, so Windows may show "Windows protected your PC": choose More info, then Run anyway. See the code signing policy.

The Claude Code plugin

Claude Code 2.1.287 or later, on the same computer as the app.

In a Claude Code session, type:

/plugin marketplace add samsonchen/agent-town-claude-code
/plugin install town-link@agent-town-claude-code

Restart Claude Code, open the app, and give it a task.

Questions

Questions

Does it control Claude Code?

No. It only watches. You keep working in your terminal, the Claude desktop app or VS Code, and the plugin never changes what Claude Code does.

Does it send my code or prompts anywhere?

No. What Claude Code is doing goes only to the app on your own computer. To name each task and pick the right hat, the plugin asks Claude's Haiku model on your own Claude plan, the same way Claude Code itself would. The app checks GitHub once a day for a newer version, which you can turn off. Read the privacy policy.

Which Claude apps does it work with?

Claude Code in a terminal, the Code tab of the Claude desktop app, and the VS Code extension, when they run on the same computer as the app. Cloud sessions and Claude Code on the web can't reach your computer, so they don't show up.

Is it a productivity dashboard?

No. It shows what is happening. It has no scores and no reports.

Is it free?

Yes. Agent-Town is open source under the Apache 2.0 license. The characters and furniture are Kenney's free CC0 models.

Is it related to other projects called agent-town?

No. This is Agent-Town for Claude Code, made for Anthropic's Claude Code. It isn't affiliated with Anthropic, or with other projects that share the name.
