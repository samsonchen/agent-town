程式碼簽章政策

簽章讓你的電腦可以確認 Agent-Town 的 app 真的來自這個專案，而且建置之後沒有被修改過。

Windows

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

（免費的程式碼簽章由 SignPath.io 提供，憑證由 SignPath Foundation 核發。）

Agent-Town 正在申請 SignPath Foundation 的開源專案計畫。核准之前，Windows 版本沒有簽章，執行安裝程式時 Windows 可能會顯示「Windows 已保護您的電腦」。

簽章的檔案：Windows app（agent-town.exe 和它的附加程式庫）以及安裝程式（agent-town-setup-<版本>.exe），發布在專案的 GitHub Releases，標籤為 windows-v<版本>。

macOS

Mac 版用 Apple Developer ID 簽章，並經過 Apple 公證，macOS 在打開前就能確認它的來源。

版本怎麼產生

  • 每個版本都從 GitHub repository 的公開原始碼建置，來自 main 分支上加了標籤的 commit，使用同一個 repository 裡的發行腳本。
  • 只簽署從本專案自己的原始碼建置出來的軟體。App 不含任何專有元件，只使用作業系統的程式庫、Windows 版使用開源的 Godot 引擎，以及 Kenney 的 CC0 模型。
  • 每個簽章請求都由下方的核准者手動核准。
  • 每位團隊成員在 GitHub 和簽章服務上都必須使用多重要素驗證。

隱私權

除非使用者或安裝、操作它的人特別要求，本程式不會將任何資訊傳送到其他網路系統，唯一的例外可以關閉：每天到 GitHub 檢查一次新版本（「設定」→「更新」）。App 和 Claude Code plugin 傳送什麼、傳到哪裡，請看隱私權政策。

回報問題

如果你認為有簽章的 Agent-Town 檔案被竄改，或對某個版本有任何疑慮，請在 GitHub 開 issue。
