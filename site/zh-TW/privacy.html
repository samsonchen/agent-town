隱私權政策

Agent-Town for Claude Code 由兩個部分組成：app（macOS 和 Windows 版）和 town-link（一個 Claude Code plugin）。兩者都沒有帳號、不收集使用統計，也不會傳任何東西給 Agent-Town 的製作者。這一頁說明每個部分讀取什麼、傳送什麼。

簡單來說

  • Claude Code 正在做的事，只會傳到你自己電腦上的 Agent-Town app，不會經過網路。
  • 為了替每個工作取名字，plugin 會透過 Claude Code、用你自己的 Claude 方案請 Claude 的 Haiku 模型幫忙。不會傳到任何其他服務。
  • App 每天到 GitHub 檢查一次有沒有新版本。可以在「設定」→「更新」關掉。
  • 除此之外，沒有任何東西會離開你的電腦。

Plugin（town-link）

town-link 會觀察 Claude Code 在做什麼：session 開啟、你輸入 prompt、使用某個工具、幫手（subagent）或背景工作開始和結束、請你核准、session 的記憶用了多少。它把這些變成簡短的訊息，透過只在你電腦內部的連線（位址 127.0.0.1）傳給 Agent-Town app。App 只接受帶有它自己產生的隨機金鑰的訊息，所以其他程式無法冒充送事件給它。

這些訊息包含：專案名稱（不含完整資料夾路徑）、每個 prompt 的開頭（就是辦公室裡工單上顯示的文字）、使用中的工具名稱、幫手和背景工作的簡短說明、使用的模型，以及 plugin 的版本。

每個新工作，town-link 會透過 Claude Code、用你自己的 Claude 方案或 API key，請 Claude 的 Haiku 模型取一個短標題、判斷工作類型；每個幫手或背景工作，則請它選一個合適的職稱。這些請求包含 prompt 的開頭或幫手的說明，Anthropic 會像處理你帳號上其他 Claude Code 請求一樣處理它們。如果你不想這樣，可以在 Claude Code 裡用 /town off 關掉 town-link。

town-link 不會改變 Claude Code 的任何行為：不會允許、拒絕或修改任何東西。App 沒有執行時，事件會直接丟棄，不會留存。

App

App 只顯示它收到的事件，結束後不保留任何東西，除了你的設定（例如語言、音效和視窗位置），這些都留在你的電腦裡。

App 啟動後不久會檢查一次，之後每天一次，向 GitHub 取得 Agent-Town 的版本清單和 plugin 的最新版本號，在有新版本時告訴你。這個請求不包含任何關於你、你的工作或你電腦的資訊，只有一般網路請求都會帶的東西（例如你的 IP 位址），由 GitHub 依它自己的隱私權聲明處理。要關掉這個檢查，請到「設定」→「更新」關閉「自動檢查更新」。

安裝程式

Mac 版（Homebrew 或 .dmg）和 Windows 安裝程式只負責安裝 app，不會傳送任何資訊。

其他元件

App 使用作業系統本身的程式庫、Windows 版使用 Godot 引擎，以及 Kenney 的 3D 模型。它們都不會代替 Agent-Town 傳送資訊。

問題

原始碼是公開的，這一頁說的每件事都可以查證。有問題或疑慮，請在 GitHub 開 issue。
